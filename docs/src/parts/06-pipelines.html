9Pipelines

9.1Dictation

The goal is Wispr Flow's feel without its memory cost: double-tap Caps Lock, talk, and the text is already there when you stop. The trick is to transcribe while you are still talking, so that when you finish only the last couple of seconds are left.

  1. Start. Double-tap Caps Lock to talk hands-free, or hold Ctrl+Alt+Space for push-to-talk. The core starts recording the mic into a ring buffer straight away, so the first word is never lost, and the indicator wakes up (§13.3). If the speech worker is not running, the core starts it now.
  2. While you talk. Voice-activity detection cuts the audio at pauses of 500 ms or more, into pieces of at most 10 s, and sends each piece to the worker as soon as it closes. With live words on, the indicator shows the last few words.
  3. Finish. Double-tap Caps Lock again, stop talking for 2 s, or let go of the push-to-talk keys; Esc cancels. The last piece goes to the worker at once. MWB waits until Ctrl, Alt and Caps Lock are released, so its paste never arrives as Ctrl+Alt+V, and Caps Lock ends in the state it started in.
  4. Write or answer. If the cursor is not in a text box, or you began with the wake word ("MWB, what's my next meeting?"), your words become a question for answer mode (§9.7). With text selected, a command such as "make this shorter" rewrites the selection (§9.2). Otherwise MWB writes.
  5. Clean-up rules, under 5 ms: drop fillers, collapse stutters, turn spoken commands into punctuation, apply your dictionary. Parakeet already outputs punctuation and capitals.
  6. Optional polish by a language model, chosen per app. Through the API it adds under a second; on the local fallback, 1 to 3 s. It is off by default on the Lean profile, because it sends what you dictated to the API; hold Shift as you finish to ask for it.
  7. Insert. Save the clipboard, put the text on it, send Ctrl+V, and restore the clipboard 300 ms later. Apps that block paste get the text typed with SendInput instead.
  8. Log the text, target app and latency to the history table, for search and re-insert.

9.2Voice commands on selected text

Select text anywhere, hold Ctrl+Alt+R, and say what you want: "shorter", "more formal", "turn this into bullet points", "translate to Hindi". MWB copies the selection, restoring your clipboard afterwards, transcribes the instruction, asks the language model to rewrite, and shows the result in a small card with Replace and Copy.

Through the API, rewriting a paragraph takes 1 to 2 s. On the local fallback it takes roughly 5 to 15 s on this laptop, so the result streams into the card as it is written; the second memory stick makes that about twice as fast.

9.3Meetings

Any video-call app, desktop or browser. Detection does not depend on one vendor. Every 5 seconds the core asks Windows which apps are using the microphone right now. Windows records when each app last started and stopped using the mic, both for packaged apps such as new Teams or WhatsApp and for desktop programs such as Zoom.exe or slack.exe. A stop time of 0 means the app is using the mic at this moment. Reading these keys takes microseconds and needs no admin rights. On this laptop, keys already exist for new Teams, Edge and Wispr Flow.

sensors/meeting_detector.py (sketch)
import winreg

MIC = r"Software\Microsoft\Windows\CurrentVersion\CapabilityAccessManager\ConsentStore\microphone"

def mic_holders() -> list[str]:
    """Every app using the microphone right now, packaged or desktop."""
    found = []
    for path, packaged in ((MIC, True), (MIC + r"\NonPackaged", False)):
        with winreg.OpenKey(winreg.HKEY_CURRENT_USER, path) as root:
            for i in range(winreg.QueryInfoKey(root)[0]):
                name = winreg.EnumKey(root, i)
                if name == "NonPackaged":
                    continue
                with winreg.OpenKey(root, name) as k:
                    try:
                        start = winreg.QueryValueEx(k, "LastUsedTimeStart")[0]
                        stop = winreg.QueryValueEx(k, "LastUsedTimeStop")[0]
                    except FileNotFoundError:
                        continue
                if start and stop == 0:                  # 0 = still using the mic
                    # desktop apps are keyed by exe path with "#" for "\"; keep the exe name
                    found.append(name if packaged else name.split("#")[-1])
    return found   # e.g. ["MSTeams_8wekyb3d8bbwe"], ["Zoom.exe"], ["brave.exe"]

Each holder is matched against config/vc_apps.yaml. When the holder is a browser, MWB reads the browser's tab titles through UI Automation, only at that moment, and looks for a known meeting site. The camera key, the app's own audio output and a meeting link in the running Outlook calendar item (a Teams, Zoom, Meet or Webex URL) raise confidence and give the meeting its title.

  • Start: a known call app holds the mic for 20 s or more, or an unknown one does and you say yes. If an Outlook calendar item is running within 10 minutes either side, its subject, organizer, attendees and meeting link are attached. The link also names the platform when the mic holder is a browser.
  • End: the mic is released for 60 s.
  • On start: the notification "Recording Sprint review (Zoom). Press Ctrl+Alt+M to stop." and the tray turns orange. During the first week MWB asks before every recording, and apps marked personal always ask.
  • Two lanes: Me (mic) and Them (system loopback), each with AI-App's VAD, gain levelling and echo removal. Loopback hears every app the same way, so no app needs special support. Later, Windows' per-process loopback can capture only the call app's audio, whichever app it is.
  • During the call: 2 threads, below-normal priority, arena off. If the CPU stays above 80 % for 30 s, for example with video and screen sharing, MWB stops transcribing, writes the audio to disk as Opus, and catches up after the call.
  • After the call: merge the lanes into one timeline marked You and Them, write notes for each 10-minute chunk, combine them into one summary, pull out decisions and action items with owners, then classify (§10).
  • No recording needed: if the platform already transcribed the meeting (Teams, Zoom cloud recordings, Google Meet, Webex), import that transcript instead. It costs no CPU, and nothing is recorded at all.

9.4Email

Explain: press Ctrl+Alt+E

Works on selected text in any mail client, including new Outlook and Outlook on the web in Brave. In classic Outlook it can also read the open or selected message directly. The card shows a two-line summary, what they want from you, deadlines as real dates, the people involved, and reply options.

Draft: hold Ctrl+Alt+E and speak

Say the gist: "tell him I'll share the build by Wednesday and I still need Kafka access". MWB writes the reply in your style and either types it at the cursor or opens it as an Outlook draft for you to edit. It never calls Send.

Your style card. Once, at night on the local model, MWB reads up to 30 of your sent emails and writes a short card: greeting, sign-off, typical length, tone and phrases you use. COM works with classic Outlook, which is installed with one profile. New Outlook has no COM, so there MWB works from selected text. A Microsoft Graph connection is a later option; it needs an app registration that IT approves.

9.5Code

Select code anywhere and press Ctrl+Alt+K. The card shows what the code does, problems (bugs, edge cases, complexity), an optimised version as a diff, and tests if you ask. Its buttons are Copy, Replace selection, and Open diff in VS Code (code --diff). MWB guesses the language from the window title, for example main.js - AI-App - Visual Studio Code. Hold the same keys and describe what you need, such as "a Java method that retries with exponential backoff", and the code is pasted at the cursor.

Through the API, gpt-oss-120b explains code and suggests optimisations quickly. The local fallback for code is Qwen3.5 4B with thinking off; it explains code well and handles small refactors. For large changes, Claude Code or Copilot in the editor is the better tool. On the Performance profile a 30B mixture-of-experts coding model runs locally.

9.7Ask MWB: answers by voice

The same double tap of Caps Lock answers questions. MWB treats what you said as a question when the cursor is not in a text box, or when you start with the wake word, "MWB" by default. You can change the word, or make the double tap always write or always answer.
