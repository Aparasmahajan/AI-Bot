20Glossary

ASR
Automatic speech recognition. Speech in, text out.
WER
Word error rate: the share of words that come out wrong. Lower is better.
× real time (RTFx)
How many times faster than the audio plays. 5× means a minute of speech takes 12 seconds.
VAD
Voice activity detection. Finds where speech starts and stops, so only speech is transcribed.
Diarization
Working out who spoke when, and giving each speaker a label.
Loopback
Recording what your speakers play. In a call, that is the other side.
LLM
Large language model. Reads and writes text: summaries, drafts, labels.
Token
A piece of a word, about three quarters of an English word on average. Model speed is quoted in tokens per second.
Prefill and decode
Reading the prompt, which is fast, and writing the answer, which is limited by memory bandwidth.
Quantization
Storing a model's numbers in fewer bits (int8, 4-bit) so it uses less memory and runs faster, at a small cost in accuracy.
GGUF, ONNX
File formats for models. llama.cpp runs GGUF; ONNX Runtime runs ONNX.
Memory bandwidth, channels
How fast RAM feeds the CPU. Two sticks in two slots (dual channel) double it.
Working set, private bytes
RAM a process has in physical memory right now, against memory it has reserved, part of which may sit in the pagefile.
Arena
onnxruntime's memory pool. Fast, but it keeps memory after a large input instead of returning it.
Worker, sidecar
A separate process that does the heavy work and can be ended to free its memory.
mmap
Mapping a model file into memory, so Windows loads pages as needed and can drop them under pressure.
Few-shot
Putting a handful of examples in the prompt to steer the model, such as your past label corrections.
RAG
Retrieval-augmented generation. Search your own data first, then let the model answer from what it found.
VC app
Any video-conferencing or calling app: Teams, Zoom, Meet, Webex, Slack huddles, WhatsApp and others.
Effort level
How hard MWB works right now, from E1 to E4: threads, model size, extra passes, live features.
Hardware fingerprint
A short ID built from CPU, RAM, GPU and NPU. When it changes, MWB re-calibrates and re-tunes itself.
API key
A password-like token that lets MWB use a cloud model such as Groq or OpenAI. For now, MWB's main route for language work.
Fallback
The local model MWB uses when the API can't be reached, or for a skill set to local-only.
Sync check
Saved test prompts run through both the API and the local model, to make sure the fallback still gives usable answers in the same format.
Thinking mode
Qwen3.5 can reason step by step before it answers. That gives better answers but is much slower on a CPU, so MWB turns it off.
Double tap
Two quick presses of the same key within 350 ms: Caps Lock to talk or ask, Alt to show or hide the indicator.
Indicator
The small floating icon at the bottom of the screen that shows what MWB is doing, like Wispr Flow's pill.
Wake word
A word you start with, "MWB" by default, to make MWB answer instead of typing what you say.
Pre-roll
A short stretch of audio, 0.4 s in MWB, kept from just before the speech starts, so the first sound of the first word isn't cut off.
whisper-cli
whisper.cpp's command-line program. MWB starts it once for each piece of meeting audio; when it exits, its memory goes back to Windows.
Event loop
The part of the core that sleeps until something happens, handles it in microseconds, and goes back to sleep.
