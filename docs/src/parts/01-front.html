MWB

A work assistant for Windows. It types what you say, keeps track of your meetings, helps with email and code, and writes your end-of-day journal. Speech runs on your laptop; for now the writing goes through an API key, so it needs almost no memory. It is sized for the 16 GB laptop you have today and scales up when you get a better one.

1Features

  • Wispr-style dictation. Double-tap Caps Lock, talk, and the text appears in whatever app you are typing in. In the built app the text arrives 0.98 s after you finish (median).
  • Ask by voice. The same double tap answers questions about your day, or anything else, in a panel that rises out of the indicator.
  • A floating indicator: the Capsule skin now, with seven more skins or your own images in Phase 5. Double-tap Alt to show or hide it.
  • The speech engines from AI-App: NVIDIA Parakeet TDT 0.6B v2 (int8) for dictation, and whisper small through whisper.cpp for meetings, which are in English, Hindi and Hinglish.
  • Automatic meeting capture in any video-call app: Teams, Zoom, Google Meet, Webex, Slack and others, desktop or browser. You and the other side are recorded on separate lanes.
  • Work or Timepass. Every meeting gets a label, a reason and a time split, and the labels improve from your corrections.
  • Email help. Explains a selected email and drafts replies in your style. It never sends anything itself.
  • Code help. Explains and optimises selected code in any editor or browser.
  • End-of-day journal with commits and their SHAs, meetings, email, notes and time per project, ready at 18:30.
  • About 36 MB at idle (private memory, measured). Models run in separate processes that start when needed and exit when idle.
  • Speech local, writing through an API for now. Speech runs on a model already installed on this laptop, and audio never leaves it. Notes, email, code and the journal go to an API (Groq, as in AI-App, with openai/gpt-oss-120b), so they need almost no memory. Qwen3.5, downloaded on 12 October, is kept in sync on this laptop as the fallback, and any skill can be set to local-only.
  • Effort you set per device. Four hardware profiles and four effort levels. On a new laptop a setup screen suggests a level and you choose.

2Applications

  • Daily stand-up and status updates
  • Timesheets and weekly reports
  • Meeting notes and action items
  • Email triage and replies
  • Quick code explanations and reviews
  • A lighter replacement for Wispr Flow, with speech recognised on the laptop

3Description

MWB is a Windows tray assistant designed so that nothing heavy stays in memory. A small core process is always running. It owns the hotkeys, the tray icon, the meeting detector, the data collectors and the database.

Dictation speech runs in a separate worker process. It starts with MWB when memory allows, or when you start talking, and exits after it has been idle for 15 minutes. Meeting speech starts whisper once for each piece of audio, and each run exits when its piece is done. Ending the process is the only reliable way to give memory back to Windows. Language work goes to an API for now; when the API can't be used, a local language worker starts and exits the same way.

Status at Rev G, 16 October 2026. Phases 1 to 3 were built on 14 October: dictation, meetings, and understanding (notes, labels, email, code, rewrite and answers). Each phase's checks that need real use, such as your own voice, a week of calls or your first 20 labels, are still open (§17). The journal (Phase 4) and the setup screen, effort levels and other skins (Phase 5) are not built yet. Where the build differs from the plan, this revision describes what was built and says why.
