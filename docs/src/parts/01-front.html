Proof-of-concept design specification

MWB

A work assistant for Windows. It types what you say, keeps track of your meetings, helps with email and code, and writes your end-of-day journal. Speech runs on your laptop; for now the writing goes through an API key, so it needs almost no memory. It is sized for the 16 GB laptop you have today and scales up when you get a better one.

Contents{{toc}}

1Features

  • Wispr-style dictation. Double-tap Caps Lock, talk, and the text appears in whatever app you are typing in. On this laptop a 5-second phrase is transcribed in 0.91 s.
  • Ask by voice. The same double tap answers questions about your day, or anything else, in a small card.
  • A floating indicator with eight skins or your own images. Double-tap Alt to show or hide it.
  • The speech engine from AI-App: NVIDIA Parakeet TDT 0.6B v2 (int8), with whisper.cpp for Hindi and Hinglish.
  • Automatic meeting capture in any video-call app: Teams, Zoom, Google Meet, Webex, Slack and others, desktop or browser. You and the other side are recorded on separate lanes.
  • Work or Timepass. Every meeting gets a label, a reason and a time split, and the labels improve from your corrections.
  • Email help. Explains a selected email and drafts replies in your style. It never sends anything itself.
  • Code help. Explains and optimises selected code in any editor or browser.
  • End-of-day journal with commits and their SHAs, meetings, email, notes and time per project, ready at 18:30.
  • About 40 MB at idle. Models run in separate processes that start when needed and exit when idle.
  • Speech local, writing through an API for now. Speech runs on a model already installed on this laptop, and audio never leaves it. Notes, email, code and the journal go to an API (Groq, as in AI-App), so they need almost no memory. Qwen3.5, downloaded on 12 October, is kept in sync on this laptop as the fallback, and any skill can be set to local-only.
  • Effort you set per device. Four hardware profiles and four effort levels. On a new laptop a setup screen suggests a level and you choose.

2Applications

  • Daily stand-up and status updates
  • Timesheets and weekly reports
  • Meeting notes and action items
  • Email triage and replies
  • Quick code explanations and reviews
  • A lighter replacement for Wispr Flow, with speech recognised on the laptop

3Description

MWB is a Windows tray assistant designed so that nothing heavy stays in memory. A small core process is always running. It owns the hotkeys, the tray icon, the meeting detector, the data collectors and the database.

Speech runs in a separate worker process. It starts when you start talking or a meeting begins, and exits after it has been idle for a while. Ending the process is the only reliable way to give memory back to Windows. Language work goes to an API for now; when the API can't be used, a local language worker starts and exits the same way.

This specification is based on an audit of your HP EliteBook 840 G8, a review of the AI-App code, and benchmarks run on this laptop. Sections 4 to 6 report what was found. Sections 7 to 16 define what to build. Sections 17 to 19 cover the plan, the risks and the decisions that are yours. If a term is new to you, section 20 explains it.
