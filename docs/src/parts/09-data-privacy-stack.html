15Privacy and security

MWB hears your meetings and sees your email, so it has to be trustworthy by construction, on a laptop your employer manages.

ConcernWhat MWB does
Where data goesAudio, transcripts and notes are stored only in your Windows profile. With default settings, the only network requests carry text for language work to your API provider.
Cloud modelsOn for language skills by default for now, off for any skill set to local-only. The first time each skill uses the API, MWB shows the exact text it sends. Audio is never sent. Check your company's policy for work content first.
Recording colleaguesA visible tray state and a notification whenever MWB records, a prompt before each recording in week 1, a policy per app (record, ask or never) with personal apps such as WhatsApp always asking, one key to stop, and import of the platform's own transcript as an alternative. Check your company's policy and local law first, since some places require everyone's consent.
A managed laptopUser-mode install, no admin rights, no drivers, no keyboard hook, an honest process name and icon, and logs IT can read. Ask IT before running it on this machine.
Data at restFiles live under your profile, which IT normally protects with BitLocker. Secrets go to Windows Credential Manager (DPAPI). Encrypting the database with SQLCipher is a v1 option.
Activity trackingApp names and window titles only. No keystrokes, no screenshots, no browser history. A denylist for apps and titles, private hours, and Ctrl+Alt+P to pause everything.
Forgetting"Forget this meeting" and "Forget today" buttons remove the rows, the audio and the journal entries together.
Untrusted textAn email or a meeting can contain instructions aimed at the model. MWB treats model output as text only: it never runs it, never sends mail and never opens links from it.
