15Privacy and security

MWB hears your meetings and sees your email, so it has to be trustworthy by construction, on a laptop your employer manages.

ConcernWhat MWB does
Where data goesAudio, transcripts and notes are stored only in your Windows profile. With default settings, the only network requests carry text for language work to your API provider.
Cloud modelsOn for language skills by default, off for any skill set to local-only. On 13 October you said work text may go to Groq. Audio is never sent. MWB logs each request's size, route and time in its database, never the text. Showing the exact text the first time each skill uses the API is still to do (Phase 5).
Recording colleaguesA visible tray state and a notification whenever MWB records, a prompt before each recording in week 1, a policy per app (record, ask or never) with personal apps such as WhatsApp always asking, one key to stop, and import of the platform's own transcript as an alternative. Check your company's policy and local law first, since some places require everyone's consent. That question is still open with IT or your manager, so for now choose "Not this one" on work calls.
A managed laptopUser-mode install, no admin rights, no drivers, no keyboard hook, an honest process name and icon, and logs IT can read. Ask IT before running it on this machine.
Data at restFiles live under your profile, which IT normally protects with BitLocker. Secrets go to Windows Credential Manager (DPAPI). Encrypting the database with SQLCipher is a v1 option.
Activity trackingApp names and window titles only. No keystrokes, no screenshots, no browser history. A denylist for apps and titles, private hours, and Ctrl+Alt+P to pause everything.
Forgetting"Forget this meeting" and "Forget today" buttons remove the rows, the audio and the journal entries together (Phase 5). Meeting audio is already deleted piece by piece as it is transcribed.
Untrusted textAn email or a meeting can contain instructions aimed at the model. MWB treats model output as text only: it never runs it, never sends mail and never opens links from it. A test scans every line of MWB's code for a send call. Citations in answers are checked against the facts MWB found, and evidence quotes in labels against the notes.
