4.2Where the memory goes

Two browsers and the Claude app hold about 9 GB between them. Wispr Flow holds 1.5 GB all day for a single job, dictation. MWB has to do far more than that job and still stay under Wispr Flow's line for most of the day. Figure 11.2 shows how.

4.3Findings

Finding 1 · cheapest speed-up

The only memory stick is a Crucial CT16G4SFRA32A (16 GB DDR4-3200) in one of two slots, so memory runs single channel. A matching second stick gives 32 GB and dual channel at 51.2 GB/s. Local LLM output speed is limited by memory bandwidth, so it roughly doubles. The integrated graphics also get the dual-channel memory Intel specifies for full Iris Xe performance. HP lists the 840 G8 at up to 64 GB (2 × 32 GB). On a managed laptop this needs IT's approval.

Finding 2 · replace, don't stack

Wispr Flow is running as 11 processes holding about 1.5 GB. MWB's dictation is built to replace it. Running both doubles the memory cost, and the two apps would compete for the microphone and for hotkeys.

Note · Python

The python command on the PATH is the Microsoft Store placeholder and prints "Python was not found". Python 3.14.7 is installed and works through the launcher as py -3.14. Its standard library already includes SQLite 3.50 with full-text search (FTS5) and Tkinter 9.0. MWB uses both, so the always-on core needs very few extra packages.
