7Requirements

Priorities use four levels. Must is in the POC. Should is in the POC if time allows. Could is nice to have. Later needs a stronger machine or a later version.

7.3Hard limits

Never
  • Never sends an email or a message. MWB writes drafts only.
  • Never uploads audio. The API receives text only, and never the text of a skill set to local-only.
  • Never records without the tray turning orange and a notification on screen.
  • Never logs keystrokes, takes screenshots or reads browser history.
  • Never loads two models at the same moment on the Lean profile. Two can stay resident together only when the memory guard finds room; otherwise the idle one exits first.
  • Never exceeds 3.5 GB in total on the Lean profile. The memory guard defers work instead.
