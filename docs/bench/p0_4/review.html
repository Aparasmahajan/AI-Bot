## What it does
The `add_tag` function appends a given `tag` to a list of tags and returns the list.  
The `average` function attempts to compute the arithmetic mean of a list of numbers.

## Problems
- `add_tag` uses a mutable default argument (`tags=[]`), causing the same list to be shared across calls.  
- `average` skips the first element because the loop starts at index 1, leading to an incorrect sum.  
- `average` will raise a `ZeroDivisionError` when `nums` is empty.

## Better version
```python
def add_tag(tag, tags=None):
    """Append a tag to a list and return the list without sharing state."""
    if tags is None:
        tags = []
    tags.append(tag)
    return tags


def average(nums):
    """Return the arithmetic mean of a sequence of numbers."""
    if not nums:
        raise ValueError("Cannot compute average of an empty sequence")
    total = sum(nums)          # sum all elements
    return total / len(nums)   # divide by the number of elements
```

## What it does

The `average` function calculates the average of a list of numbers, but it skips the first element in the calculation.

A process is an independent execution unit that has its own memory space, resources, and at least one thread, while a thread is a lightweight execution path that runs within a process and shares that process’s memory and resources.
